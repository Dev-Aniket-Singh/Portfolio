# Aniket Singh — Portfolio

A responsive, single-page developer portfolio built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The GitHub activity panel is intentionally marked as a placeholder until live profile data is connected. The contact form opens a prefilled email in the visitor's mail application; it does not submit to a server.
